# Neerova Design System

## Design Philosophy

Create a premium service-business website that feels trustworthy, modern, and conversion-focused.

The website should feel like a high-end local service company rather than a generic plumbing website.

Keywords:

- Premium
- Reliable
- Modern
- Professional
- Clean
- Confident
- Human

---

# Visual Direction

Blend:

- Modern SaaS clarity
- Local service trust
- Luxury construction aesthetics

Avoid:

- Cheap stock website feel
- Overly corporate layouts
- Excessive animations

# Imagery Style

Use:

- Real plumbers
- Real tools
- On-site service images
- Customer interactions

Avoid:

- Cartoon illustrations
- Generic vectors
- Unrealistic renders

---

# Motion Design

Subtle only

- Fade Up
- Scale In
- Marquee Scroll
- Card Hover Lift

No excessive parallax.

---

# Mobile Experience

Prioritize:

- One-thumb navigation
- Quick CTA access
- Fast loading
- Large touch targets
